# UDI-DICOM Conformance Suite Private

Private repository. NDA required. No PHI. Synthetic until approved sample intake.
Do not push cases to the public validator repository. The public validator is a
dependency and not a replacement for the private suite.

## v0.6 Governance

v0.6 adds partner feedback intake, private asset governance, private case
lifecycle documentation, synthetic case authoring guidance, and public paper
support boundary material. It does not add real vendor rules, real samples,
PHI, raw DICOM files, clinical validation, regulatory approval, or
certification.
