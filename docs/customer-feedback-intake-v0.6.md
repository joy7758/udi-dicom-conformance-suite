# Customer Feedback Intake v0.6

Customer review feedback must be categorized before action:

- discovery question
- sample intake question
- de-identification concern
- validation report question
- delivery package question
- pilot handoff question
- out-of-scope request

Do not accept PHI, raw DICOM files into delivery packages, real clinical
reports, real customer names, real hospital names, clinical validation requests,
regulatory approval requests, or certification requests through this intake.

Real cooperation requires NDA and de-identification review before work begins.
