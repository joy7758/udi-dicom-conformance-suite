# No Real Vendor Rules Policy

The private conformance suite uses synthetic cases and placeholder vendor
folders only. It must not encode real vendor-confidential rules, undocumented
field behavior, proprietary mappings, or customer-specific acceptance criteria.

Allowed:

- synthetic partner-safe cases
- synthetic private regression cases
- placeholder vendor strategy notes
- profile compatibility summaries

Not allowed:

- real vendor-confidential rules
- PHI
- raw DICOM files
- real hospital data
- clinical validation claims
- regulatory approval claims
- certification claims
