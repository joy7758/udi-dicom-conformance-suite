# Partner Answer Boundary v0.5

Safe answers must:

- Say synthetic or de-identified material is required before any technical
  review.
- Distinguish public validator, partner pack, and private suite.
- Keep registry fixture review separate from live lookup.
- State that Device UID is not UDI-DI.
- State that FDO-style mapping is a metadata boundary, not an official FDO
  implementation claim.

Safe answers must not:

- Promise hospital deployment.
- Promise regulatory compliance outcomes.
- Promise clinical validation.
- Promise certification.
- Accept PHI or raw DICOM files through partner dry-run channels.
- Disclose complete private case content.
