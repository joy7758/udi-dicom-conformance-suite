# Partner Feedback Intake v0.6

Partner feedback must be categorized before any action:

- partner pack question
- expected output mismatch
- evidence boundary concern
- vendor mapping question
- registry fixture question
- out-of-scope request

Do not accept PHI, real patient samples, real hospital data, real vendor
confidential rules, real device serial numbers, regulatory certification
requests, clinical validation requests, or raw DICOM files through this intake.

Any real cooperation requires NDA and de-identification review before technical
work begins.
