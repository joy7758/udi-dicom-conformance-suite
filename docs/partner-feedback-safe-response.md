# Partner Feedback Safe Response

Safe response pattern:

1. Acknowledge the feedback category.
2. Restate that review uses synthetic partner-safe material.
3. Point to the partner dry run package or question bank.
4. State whether the item is accepted, needs internal review, or is out of
   scope.

Required boundary sentence:

This response is technical review support only; it contains no PHI, no raw
DICOM, no real vendor confidential rules, no clinical validation, no regulatory
approval, and no certification.
