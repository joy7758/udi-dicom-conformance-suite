# Partner Feedback Scope Policy

Accepted in v0.6:

- partner pack questions
- expected output mismatch reports using synthetic partner-safe cases
- evidence boundary concerns
- vendor mapping questions that do not disclose confidential rules
- registry fixture questions

Not accepted in v0.6:

- real patient samples
- real hospital data
- real vendor confidential rules
- raw DICOM files
- clinical validation requests
- regulatory approval requests
- certification requests
- public disclosure of private cases

Real cooperation requires NDA and de-identification gates.
