# Partner Intake Minimum Package

Minimum safe intake items:

- partner contact role without patient or hospital identifiers
- public validator version under review
- target profile version
- synthetic DICOM metadata examples if examples are needed
- registry fixture strategy preference
- expected review questions

Do not accept:

- PHI
- raw DICOM files
- real patient identifiers
- real hospital identifiers
- real vendor-confidential rules before an approved NDA route

The intake package supports review and report preparation only. It is not
clinical validation, regulatory approval, or certification.
