# Partner-Safe Language v0.5

Use:

- "technical review"
- "synthetic partner-safe case"
- "offline registry fixture"
- "deterministic receipt"
- "boundary audit"
- "FDO-style metadata mapping"

Do not use:

- "clinical validation completed"
- "regulatory approval granted"
- "certified for clinical use"
- "hospital deployment approved"
- "real customer acceptance"

Required boundary sentence:

This material is synthetic technical review support only; it contains no PHI,
no raw DICOM files, no complete private case content, and it is not clinical
validation, not regulatory approval, and not certification.
