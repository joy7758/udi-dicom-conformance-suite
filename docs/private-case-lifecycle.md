# Private Case Lifecycle

1. Author synthetic case.
2. Confirm no PHI, no raw DICOM, no real hospital data, no real vendor
   confidential rule, and no real device serial number.
3. Add expected receipt summary.
4. Add to private case index.
5. Run case index, regression baseline, partner pack, leakage audit, release
   asset build, partner dry run, evidence boundary audit, and private asset
   governance audit.
6. Keep full private case content internal.
