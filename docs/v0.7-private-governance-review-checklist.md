# v0.7 Private Governance Review Checklist

Use this checklist before partner-facing discussion or private-suite release
review.

- Confirm `partner-pack/generated/` excludes private case paths and complete
  private case content.
- Confirm `partner-dry-run/generated/` remains partner-safe and synthetic.
- Confirm private release assets contain no PHI and no raw DICOM.
- Confirm public-paper support language says only that controlled
  partner-review infrastructure exists.
- Confirm no report claims clinical validation, regulatory approval,
  certification, real vendor approval, or hospital deployment.
- Confirm any real cooperation request is routed to NDA and de-identification
  review before technical work begins.
