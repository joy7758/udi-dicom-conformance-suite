# v0.7 Service Feedback Prep

This v0.7 pass prepares customer feedback handling and safe handoff review after
v0.6 service governance. It is a preparation layer only and does not add service
capabilities.

## Scope

- Confirm customer feedback is categorized before action.
- Confirm synthetic customer dry-run outputs remain customer-safe.
- Confirm service governance audit has no hits.
- Confirm safe handoff package has no PHI, no raw DICOM, no real customer name,
  and no real hospital name.
- Confirm real cooperation still requires NDA and de-identification review.

## Required Commands

```bash
python scripts/redact_check.py .
python scripts/build_service_readiness_matrix.py
python scripts/build_pilot_kit.py
python scripts/build_delivery_package.py --synthetic-demo
python scripts/check_delivery_package.py delivery/generated
python scripts/run_synthetic_pilot_e2e.py
python scripts/check_synthetic_pilot_outputs.py artifacts/synthetic-pilot-e2e
python scripts/build_delivery_audit_trail.py --synthetic-demo
python scripts/run_synthetic_customer_dry_run.py
python scripts/check_synthetic_customer_dry_run.py artifacts/synthetic-customer-dry-run
python scripts/audit_service_language.py
python scripts/audit_service_governance.py
python scripts/build_safe_handoff_package.py
python scripts/check_safe_handoff_package.py artifacts/safe-handoff-package-v0.6
pytest -q
```

## Boundary

- no PHI
- no raw DICOM
- not clinical validation
- not regulatory approval
- not certification
- no fake DOI
- no real customer or real hospital data
- synthetic examples only
- FDO-style mapping only
- no robot operation evidence
