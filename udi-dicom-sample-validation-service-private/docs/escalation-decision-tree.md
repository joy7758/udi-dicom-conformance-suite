# Escalation Decision Tree

1. Suspected PHI appears.
   - Stop.
   - Do not package.
   - Request a safe replacement artifact.

2. Raw DICOM original appears.
   - Stop.
   - Do not package.
   - Request a derived synthetic or approved de-identified summary.

3. A reviewer asks for clinical validation wording.
   - Decline that wording.
   - Use review/report wording.

4. A reviewer asks for regulatory approval or certification wording.

5. A reviewer asks to use the synthetic customer dry run as a customer approval.
   Response: escalate and restate that v0.5 outputs are technical review
   materials only.

6. A reviewer asks for pricing commitments in the technical report. Response:
   remove pricing language and route commercial discussion outside the
   validation report.
   - Decline that wording.
   - Use evidence consistency review wording.

5. Synthetic pilot artifacts pass checks.
   - Build delivery package.
   - Build delivery audit trail.
   - Complete pilot handoff checklist.
