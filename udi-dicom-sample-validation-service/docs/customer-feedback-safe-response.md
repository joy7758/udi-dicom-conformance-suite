# Customer Feedback Safe Response

Safe response pattern:

1. Acknowledge the feedback category.
2. Restate the technical review boundary.
3. Confirm whether NDA and de-identification gates are required.
4. Provide a customer-safe next step or mark the request out of scope.

Required boundary sentence:

This response is technical review support only; it contains no PHI, no raw
DICOM, no real clinical report, no clinical validation, no regulatory approval,
and no certification.
