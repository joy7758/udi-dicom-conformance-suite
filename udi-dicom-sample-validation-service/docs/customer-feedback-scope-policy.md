# Customer Feedback Scope Policy

Accepted in v0.6:

- discovery questions
- sample intake boundary questions
- de-identification concerns
- validation report questions
- delivery package questions
- pilot handoff questions

Not accepted in v0.6:

- PHI intake
- raw DICOM delivery
- real clinical reports
- clinical validation requests
- regulatory approval requests
- certification requests
- hospital deployment promises
- commercial packaging

Real cooperation requires NDA and de-identification gates.
